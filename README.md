# Plataforma de Desenvolvimento — PIC16F877A

Plataforma de desenvolvimento e prototipagem eletrônica baseada no microcontrolador **PIC16F877A**, projetada com o objetivo de facilitar o desenvolvimento e teste de aplicações embarcadas.

O projeto foi desenvolvido integralmente no **KiCad**, incluindo **esquemático eletrônico, layout da PCB e modelo 3D da placa**.

---

## 📌 Sobre o Projeto

A placa foi desenvolvida como uma plataforma própria para utilização do **PIC16F877A**, disponibilizando os pinos do microcontrolador para conexão de sensores, atuadores e outros periféricos durante o desenvolvimento de sistemas embarcados.

O projeto também possui uma interface de comunicação baseada no **CH340G**, permitindo comunicação USB/Serial com a plataforma.

---

## 🔧 Desenvolvimento do Hardware

O desenvolvimento do projeto envolveu:

- Elaboração do esquemático eletrônico;
- Seleção e integração dos componentes;
- Integração do microcontrolador PIC16F877A;
- Interface USB/Serial utilizando CH340G;
- Disponibilização dos pinos do microcontrolador;
- Desenvolvimento do layout da PCB;
- Roteamento das trilhas;
- Modelagem e visualização 3D da placa;
- Verificação do projeto utilizando as ferramentas do KiCad.
